# THS hero: 3D mockup video

A 5-second (150 frames at 30fps, 1920x1080) Remotion composition. The THS hero screen swings up out of depth in 3D, orbits slowly with a glass sheen, then flies out to the right.

```bash
npm i
npm run dev      # preview in Remotion Studio
npm run render   # writes out/hero-mockup.mp4
```

- Composition: `src/HeroMockup.tsx` (timing constants at the top)
- Screenshot: `public/ths-hero.webp`
